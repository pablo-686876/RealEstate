# 🏠 RealEstate Analytics

Фронтенд-часть приложения, расширяющего функционал сайта объявлений SS.lv. Позволяет пользователю вставить ссылку на объявление и мгновенно получить историю сделок по аналогичным объектам недвижимости, а также подробный статистический анализ рынка.

> **Примечание:** В текущей версии клиентская часть работает с моковыми (тестовыми) данными, эмулирующими ответ реального сервера.

## 💡 Как пользоваться (Демонстрация)
Поскольку проект использует моковые данные, для демонстрации работы:
1. Скопируйте любую ссылку на объявление с SS.lv (или используйте тестовую ссылку).
2. Вставьте её в поле поиска на главной странице приложения.
3. Приложение отобразит заранее подготовленные данные из файла `public/db/data.json` и их аналитику.

## 🚀 Быстрый старт

Для запуска проекта на локальном компьютере убедитесь, что у вас установлен [Node.js](https://nodejs.org/) (версии 18 или выше).

```
npm install
npm run dev
```

Открой http://localhost:5173
